## B. Correctness & Edge Cases

- **Over-scrub risk (the phase's named risk)**: mixed decision-log sections carry
  contracts Phase 07 depends on. Rule: in mixed sections delete a line only if it is
  about hooks; when a line is ambiguous, keep it. The isolated commit (AC6) is the
  safety net.
- **Generated-copy drift**: `claude/learnings/cross-phase-decisions.md` is propagator
  output; edit only the `.github/` source and regenerate with `--once` so the two
  cannot diverge.
- **Cross-reference dangling links**: after deleting PHASE_01/02/04 and `docs/hooks/`,
  grep the surviving docs (including `docs/phases/PHASE_03/`, `PHASE_05/`,
  `PHASE_07/`, and `dev/feature/` manifests are exempt — historical records) for
  links into the deleted paths; fix links in the six standard docs and roadmap only.

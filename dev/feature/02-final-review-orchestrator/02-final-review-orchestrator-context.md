## Architectural Decisions

- **One agent file, shared rules by reference**: all cross-evaluator rules (report naming, severity, ≤10-line contract, partial-failure semantics) live in `phase-final-review-conventions` and are loaded, never restated. No report templates in the orchestrator (they live in `phase-final-review-report`).
- **Numbered-orchestrator house style**: model on `04-phase-execute.agent.md` — YAML frontmatter with `name`/`description`/`tools`/`agents`, "You do NOT do X yourself; you coordinate subagents" role statement, fail-loud validation steps, delegation phrasing consistent with the `implementation-pipeline-loop` skill.
- **Preflight as a linear checklist**: baseline → subphase discovery → artifact inventory → model check, with exactly one loud failure mode per step. This is the densest section; resist branching complexity.
- **Publishes downstream contracts**: the evaluator invocation prompt shape and the not-run record format are defined in this agent's instructions and consumed by features 03–06. They must align with `phase-final-review-conventions`.
- **Worktree work is delegated**: baseline checkout goes through `05a-baseline-worktree`; the orchestrator never runs git worktree commands itself.
- **Ledger fallback is first-class**: commit-message conventions (`eval:` prefixes) are the durable signal; ledgers are local-only bonuses. Malformed/empty ledger → treat as absent. Fallback exhausted → present candidates and require user choice, never guess.

## Constraints

- The orchestrator **never reads code, diffs, or full subphase docs** — only structured reports under `dev/phase-final-review/PHASE_0N/` (AC2). Enforce the ≤10-line return-summary contract on every spawned subagent.
- **User confirmation is mandatory** for the baseline commit on both ledger and fallback paths.
- **Never report GO while any check is missing** — ceiling is "no blockers found, coverage incomplete."
- Model-tier declaration: deep-judgment evaluators (05b, 05e, 05f, 05l) on top tier; mechanical sweeps (05g, 05j, 05k) on cheap tier; warn at startup when not on a state-of-the-art model, before any work.
- Verdict write-back edits **only** the target phase's status line in `PROJECT_ROADMAP.md` and the phase summary — never restructure the roadmap (mirrors the phase-refiner roadmap-editing rule).
- Full-re-run policy after remediation: no partial re-run machinery.
- Zero subphase directories discovered → refuse and point at `prod-code-review` for un-subdivided phases.
- Source-of-truth authoring: the agent is written in `.github/agents/` only; harness outputs are generated by propagation, never hand-edited.

## Architectural Decisions

- **05l is synthesis-only**: a reader + template-filler with two hard rules — severity-ordered blocking list, and the no-GO-with-missing-checks ceiling ("no blockers found, coverage incomplete"). It must not restate report content; it ranks, cross-references, and verdicts. It never reads code.
- **Report existence is the evidence**: a missing report file at synthesis time is treated as a not-run check regardless of what the evaluator claimed. Not-run checks are enumerated by name in the readiness report.
- **Conflicting severities** for the same underlying issue across reports: 05l takes the highest severity and cross-references both sources.
- **05l extends `prod-code-review` one level up**: references its conventions (whole phase vs. single feature set); does not duplicate or modify them.
- **05i is draft-only**: mines review records, fix commits, and QA failures; drafts `.github/learnings/` entries and instruction-file update proposals for the existing instructions-writer/evaluator loop. It never edits instruction files or commits learnings itself.
- **Empty harvest is valid** for 05i in general ("none found" plus the corpus examined), but AC8 requires the real-history run to produce at least one draft.
- **Severity vocabulary** comes from the `phase-final-review-conventions` skill, not from 05l's own text.
- Both agents follow the lettered-subagent house style, honor conventions report locations and the ≤10-line return contract; 05l is top-tier per the model-tier policy (05i is not named top-tier).

## Constraints

- 05l reads evaluator reports only — never source code, never other agents' internals; inputs are pinned to the `phase-final-review-report` templates.
- Neither agent writes outside `dev/phase-final-review/` and draft-proposal locations.
- The ≤10-line return-summary contract from `phase-final-review-conventions` is a hard requirement.
- Dry runs must never touch the real roadmap: verdict write-back (AC7) is exercised against fixture copies of the planning docs; if the fixture lacks a roadmap copy, record write-back as not-performed with reason.
- The fixture contains Phase 02's genuine NO-GO case: a NO-GO verdict from the AC5 dry run is expected and correct; P2-SEC-01..03 must appear in the blocking list.
- Propagation is glob-driven — new agent files in `.github/agents/` are picked up automatically; no script change expected.
